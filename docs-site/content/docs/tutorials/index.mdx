Each tutorial picks one realistic embedded scenario and walks through
it end-to-end: the problem, the API choice, the code, and the
verification step. By the end you have a `.c` file you can copy into
an `examples/` directory and flash.

If you haven't already, finish [Get started](/docs/getting-started)
first — these tutorials assume your build and flash workflow is up.

## Tutorial format

Every tutorial follows the same shape so you know what you're getting:

<Steps>
  <Step>**What you'll build** — a working program in 50–100 lines.</Step>
  <Step>**What you'll learn** — the API choices and the reasons behind them.</Step>
  <Step>**Hardware needs** — usually just the Arduino Uno. Some tutorials need a button or an LED on a specific pin.</Step>
  <Step>**Step-by-step code** — broken down into 5–10 numbered steps with explanations.</Step>
  <Step>**Verify** — what you should see on the board, with troubleshooting.</Step>
  <Step>**Try this next** — variations that build muscle memory.</Step>
</Steps>

If a tutorial doesn't deliver, [open an issue](https://github.com/sitharaj88/MicroRTOS/issues) — we'd
rather rewrite it than leave it confusing.
