---
title: Tickless idle
description: Suppress the periodic tick during long sleeps for battery-powered designs.
---

The default scheduler runs Timer0 at 1 kHz so every 1 ms you wake the
CPU, run the tick handler, and probably go right back to sleep — wasteful
for battery-powered designs. Tickless idle suppresses the tick when the
system goes idle, reprogramming the hardware timer to fire only at the
next scheduled event.

Enabled by `MR_USE_TICKLESS_IDLE=1`.

```c
#include "micrortos.h"
```

## `mr_tickless_enable`

<Signature
  name="mr_tickless_enable"
  signature={`void mr_tickless_enable(bool enable);`}
/>

Master switch. Disable to fall back to regular periodic ticking
(useful for debugging timing-sensitive code).

<Callout type="warn">
Some peripherals stop in deep sleep (USART, ADC, SPI). Configure wake
sources before enabling `POWER_DOWN`.
</Callout>

## Tunables

```c
#define MR_USE_TICKLESS_IDLE   1
#define MR_TICKLESS_MIN_TICKS  2     /* don't go tickless for shorter sleeps */
#define MR_TICKLESS_MAX_TICKS  1000  /* hardware timer ceiling */
```

## Example: sensor wake cycle

```c
void sensor_task(void *arg) {
    while (1) {
        sample_and_report();
        mr_task_delay(MR_MS_TO_TICKS(5000));   /* 5 s sleep */
    }
}

int main(void) {
    mr_kernel_init();
    mr_tickless_init();
    mr_tickless_enable(true);
    mr_tickless_set_sleep_mode(MR_SLEEP_POWER_DOWN);

    mr_task_create(&sensor_tcb, "sensor", sensor_task, NULL, 2,
                   sensor_stack, sizeof(sensor_stack));

    mr_kernel_start();
}
```

Measured current draw on an Uno: ~0.3 mA average vs ~12 mA constantly
ticking — a 40× improvement.
