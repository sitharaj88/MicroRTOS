---
title: Tickless
description: Long idle sleeps with the tick suppressed.
---

Enabled by `MR_USE_TICKLESS_IDLE=1`.

## `mr_tickless_init`

```c
void mr_tickless_init(void);
```

Initializes tickless state. Call after `mr_kernel_init` and before
`mr_kernel_start`.

## `mr_tickless_enable`

```c
void mr_tickless_enable(bool enable);
```

Master switch. Disable to fall back to regular periodic ticking
(useful for debugging timing-sensitive code).

## `mr_tickless_set_sleep_mode`

```c
typedef enum {
    MR_SLEEP_IDLE,        /* CPU stops; peripherals run */
    MR_SLEEP_ADC,
    MR_SLEEP_STANDBY,
    MR_SLEEP_POWER_DOWN,  /* deepest; external wake only */
} mr_sleep_mode_t;

void mr_tickless_set_sleep_mode(mr_sleep_mode_t mode);
```

Pick the deepest sleep mode your wake sources support.

## Hooks (`MR_USE_TICKLESS_HOOKS=1`)

```c
void mr_tickless_pre_sleep_hook(uint32_t expected_ticks);
void mr_tickless_post_sleep_hook(uint32_t slept_ticks);
```

Implement to power-manage peripherals around each sleep cycle.

## Statistics

```c
uint32_t mr_tickless_get_sleep_count(void);
uint32_t mr_tickless_get_total_slept(void);
```

## Tunables

```c
#define MR_USE_TICKLESS_IDLE   1
#define MR_TICKLESS_MIN_TICKS  2     /* don't go tickless for shorter sleeps */
#define MR_TICKLESS_MAX_TICKS  1000  /* hardware timer ceiling */
```
