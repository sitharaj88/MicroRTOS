---
title: Mutex
description: Recursive mutexes with priority inheritance.
---

Enabled by `MR_USE_MUTEXES=1` (default).

## `mr_mutex_init`

```c
void mr_mutex_init(mr_mutex_t *mutex);
```

Initializes a mutex to the unlocked state. Caller-allocated.

## `mr_mutex_lock`

```c
mr_status_t mr_mutex_lock(mr_mutex_t *mutex, uint32_t timeout);
```

Locks the mutex, blocking up to `timeout` ticks if it's held by another
task. Recursive — a task can lock its own mutex N times and must unlock
N times to release.

Returns:

- `MR_OK` on success
- `MR_ERR_TIMEOUT` if the mutex was still held when the timeout expired
- `MR_ERR_PARAM` on `NULL` mutex

### Priority inheritance

If a higher-priority task blocks on a mutex held by a lower-priority
task, the holder is boosted to the waiter's priority. When the holder
releases, it returns to its base priority. This prevents unbounded
priority inversion.

## `mr_mutex_unlock`

```c
mr_status_t mr_mutex_unlock(mr_mutex_t *mutex);
```

Releases one level of recursion. If recursion count reaches 0, wakes the
highest-priority waiter (if any).

Returns `MR_ERR_STATE` if called by a task that doesn't hold the
mutex.

## `mr_mutex_try_lock`

```c
mr_status_t mr_mutex_try_lock(mr_mutex_t *mutex);
```

Non-blocking. Equivalent to `mr_mutex_lock(mutex, MR_NO_WAIT)`.

## `mr_mutex_get_owner`

```c
mr_tcb_t *mr_mutex_get_owner(mr_mutex_t *mutex);
```

Returns the TCB of the current holder, or `NULL` if unlocked. For
debugging and introspection.

## Example

```c
static mr_mutex_t spi_lock;

void init(void) { mr_mutex_init(&spi_lock); }

uint16_t read_sensor(uint8_t addr) {
    if (mr_mutex_lock(&spi_lock, MR_MS_TO_TICKS(100)) != MR_OK) {
        return 0xFFFF;     /* timeout — busy */
    }
    uint16_t val = spi_xfer(addr);
    mr_mutex_unlock(&spi_lock);
    return val;
}
```
