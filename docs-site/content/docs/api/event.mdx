---
title: Event groups
description: Wait on bit patterns — any-of or all-of, with timeout.
---

An event group is a 32-bit (or 16-bit on AVR) bitmap. Tasks set, clear,
and wait on any subset of bits. It's the cleanest way to express
"wake me when X or Y happens" without juggling multiple semaphores.

Enabled by `MR_USE_EVENT_GROUPS=1` (default).

```c
#include "micrortos.h"
```

## Pattern: wake on any of several conditions

```c
#define EVT_BUTTON  (1U << 0)
#define EVT_TIMEOUT (1U << 1)
#define EVT_DATA    (1U << 2)

static mr_event_t events;

void main_task(void *arg) {
    while (1) {
        uint32_t fired = mr_event_wait(
            &events,
            EVT_BUTTON | EVT_TIMEOUT | EVT_DATA,
            /* wait_all      */ false,
            /* clear_on_exit */ true,
            MR_WAIT_FOREVER
        );
        if (fired & EVT_BUTTON)  handle_button();
        if (fired & EVT_TIMEOUT) handle_timeout();
        if (fired & EVT_DATA)    handle_data();
    }
}
```

---

## Pattern: barrier (wait for all)

Three workers, one master. Master waits until all three set their bit.

```c
#define W1_DONE (1U << 0)
#define W2_DONE (1U << 1)
#define W3_DONE (1U << 2)

mr_event_wait(&events,
              W1_DONE | W2_DONE | W3_DONE,
              /* wait_all */ true,
              /* clear */ true,
              MR_WAIT_FOREVER);
combine_results();
```
