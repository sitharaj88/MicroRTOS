---
title: Queue
description: Fixed-size message queue with blocking send and receive.
---

Enabled by `MR_USE_QUEUES=1` (default).

## `mr_queue_init`

```c
void mr_queue_init(mr_queue_t *queue,
                     void         *buffer,
                     uint16_t      item_size,
                     uint16_t      capacity);
```

| Argument | Meaning |
|---|---|
| `buffer` | Caller-allocated storage, at least `item_size * capacity` bytes |
| `item_size` | Size of each message in bytes |
| `capacity` | Maximum number of pending messages |

## `mr_queue_send`

```c
mr_status_t mr_queue_send(mr_queue_t *queue,
                               const void   *item,
                               uint32_t      timeout);
```

Copies `item` into the queue tail. Blocks up to `timeout` if full.
Returns `MR_OK`, `MR_ERR_TIMEOUT`, or `MR_ERR_FULL` (on
non-blocking).

## `mr_queue_send_front`

```c
mr_status_t mr_queue_send_front(mr_queue_t *queue,
                                     const void   *item,
                                     uint32_t      timeout);
```

Same as `send`, but inserts at the head — for priority/urgent messages.

## `mr_queue_send_from_isr`

```c
mr_status_t mr_queue_send_from_isr(mr_queue_t *queue,
                                        const void   *item,
                                        bool         *yield_required);
```

ISR-safe, non-blocking.

## `mr_queue_receive`

```c
mr_status_t mr_queue_receive(mr_queue_t *queue,
                                  void         *item,
                                  uint32_t      timeout);
```

Copies the head message into `item` and removes it. Blocks up to
`timeout` if empty.

## `mr_queue_receive_from_isr`

```c
mr_status_t mr_queue_receive_from_isr(mr_queue_t *queue,
                                           void         *item,
                                           bool         *yield_required);
```

## `mr_queue_peek`

```c
mr_status_t mr_queue_peek(mr_queue_t *queue,
                               void         *item,
                               uint32_t      timeout);
```

Reads the head without removing.

## `mr_queue_count`

```c
uint16_t mr_queue_count(mr_queue_t *queue);
uint16_t mr_queue_spaces_available(mr_queue_t *queue);
bool     mr_queue_is_empty(mr_queue_t *queue);
bool     mr_queue_is_full(mr_queue_t *queue);
```

## `mr_queue_reset`

```c
void mr_queue_reset(mr_queue_t *queue);
```

Drops all pending messages. Doesn't touch waiters.

## Example

```c
typedef struct { uint16_t code; uint32_t value; } event_t;

static event_t       buffer[8];
static mr_queue_t  events;

void init(void) {
    mr_queue_init(&events, buffer, sizeof(event_t), 8);
}

void producer(void *arg) {
    while (1) {
        event_t e = { .code = 1, .value = mr_tick_get() };
        mr_queue_send(&events, &e, MR_WAIT_FOREVER);
        mr_task_delay(MR_MS_TO_TICKS(100));
    }
}

void consumer(void *arg) {
    event_t got;
    while (1) {
        if (mr_queue_receive(&events, &got, MR_WAIT_FOREVER) == MR_OK) {
            process(&got);
        }
    }
}
```
