---
title: Semaphore
description: Binary and counting semaphores for signaling and resource counting.
---

A semaphore is a counter you can block on. Binary semaphores
(`max = 1`) are perfect for ISR-to-task signaling. Counting semaphores
manage pools of resources.

Enabled by `MR_USE_SEMAPHORES=1` (default).

```c
#include "micrortos.h"
```

## Pattern: ISR → task signal

```c
static mr_sem_t rx_ready;

void init(void) {
    mr_sem_init(&rx_ready, /* max */ 1, /* initial */ 0);
}

void uart_rx_isr(void) {
    bool yield;
    mr_sem_give_from_isr(&rx_ready, &yield);
    /* port-specific: schedule a context switch if yield is true */
}

void rx_task(void *arg) {
    while (1) {
        mr_sem_take(&rx_ready, MR_WAIT_FOREVER);
        consume_rx_buffer();
    }
}
```

---

## Pattern: resource pool

A counting semaphore caps concurrent access to a pool of N resources.

```c
static mr_sem_t slots;

void init(void) {
    mr_sem_init(&slots, /* max */ 4, /* initial */ 4);
}

void use_slot(void) {
    mr_sem_take(&slots, MR_WAIT_FOREVER);   /* wait for a slot */
    do_work();
    mr_sem_give(&slots);                     /* release */
}
```

At most 4 tasks run `do_work` concurrently.
