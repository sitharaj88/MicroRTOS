---
title: Semaphore
description: Binary and counting semaphores.
---

Enabled by `MR_USE_SEMAPHORES=1` (default).

## `mr_sem_init`

```c
void mr_sem_init(mr_sem_t *sem, uint32_t max_count, uint32_t initial);
```

| Argument | Meaning |
|---|---|
| `max_count` | Maximum count. `1` = binary semaphore. |
| `initial` | Starting count (`0..max_count`). |

## `mr_sem_take`

```c
mr_status_t mr_sem_take(mr_sem_t *sem, uint32_t timeout);
```

Decrements the counter, blocking up to `timeout` ticks if the counter
is zero. Returns `MR_OK` or `MR_ERR_TIMEOUT`.

## `mr_sem_give`

```c
mr_status_t mr_sem_give(mr_sem_t *sem);
```

Increments the counter. Wakes the highest-priority waiter (if any).
Returns `MR_ERR_FULL` if already at `max_count`.

## `mr_sem_give_from_isr`

```c
mr_status_t mr_sem_give_from_isr(mr_sem_t *sem, bool *yield_required);
```

ISR-safe. If `*yield_required` is set on return, request a context
switch from the ISR's exit path.

## `mr_sem_get_count`

```c
uint32_t mr_sem_get_count(mr_sem_t *sem);
```

Snapshot of the current count.

## Pattern: ISR-to-task signaling

```c
static mr_sem_t rx_ready;

void init(void) {
    mr_sem_init(&rx_ready, /* max */ 1, /* initial */ 0);
}

void uart_rx_isr(void) {
    bool yield;
    mr_sem_give_from_isr(&rx_ready, &yield);
    /* port-specific: trigger context switch if yield is true */
}

void rx_task(void *arg) {
    while (1) {
        mr_sem_take(&rx_ready, MR_WAIT_FOREVER);
        consume_rx_buffer();
    }
}
```

## Pattern: resource pool

```c
static mr_sem_t slots;  /* counting */

void init(void) {
    mr_sem_init(&slots, /* max */ 4, /* initial */ 4);
}

void use_slot(void) {
    mr_sem_take(&slots, MR_WAIT_FOREVER);   /* wait for a slot */
    do_work();
    mr_sem_give(&slots);                       /* release */
}
```

The counter caps concurrent users at 4.
