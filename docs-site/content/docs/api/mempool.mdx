---
title: Memory pool
description: Fixed-block O(1) allocation.
---

Enabled by `MR_USE_MEMORY_POOLS=1` (default).

## `mr_mempool_init`

```c
void mr_mempool_init(mr_mempool_t *pool,
                       void           *buffer,
                       uint16_t        block_size,
                       uint16_t        block_count);
```

| Argument | Meaning |
|---|---|
| `buffer` | Caller-allocated storage, `block_size * block_count` bytes |
| `block_size` | Bytes per block (must be `>= sizeof(void *)`; rounded up otherwise) |
| `block_count` | Number of blocks |

## `mr_mempool_alloc`

```c
void *mr_mempool_alloc(mr_mempool_t *pool, uint32_t timeout);
```

Returns a pointer to a free block, or `NULL` on timeout. Blocks up to
`timeout` ticks if the pool is empty.

## `mr_mempool_free`

```c
mr_status_t mr_mempool_free(mr_mempool_t *pool, void *block);
```

Returns a block to the pool. Validates that the block is within the
pool's range (`MR_ERR_PARAM` otherwise).

## ISR-safe variants

```c
void          *mr_mempool_alloc_from_isr(mr_mempool_t *pool);
mr_status_t  mr_mempool_free_from_isr(mr_mempool_t *pool,
                                           void *block,
                                           bool *yield_required);
```

## Queries

```c
uint16_t mr_mempool_available(mr_mempool_t *pool);
uint16_t mr_mempool_total(mr_mempool_t *pool);
uint16_t mr_mempool_block_size(mr_mempool_t *pool);
bool     mr_mempool_is_empty(mr_mempool_t *pool);
```

## Example

```c
#define SLOTS 8
#define SIZE  32

static uint8_t        memory[SIZE * SLOTS];
static mr_mempool_t pool;

void init(void) {
    mr_mempool_init(&pool, memory, SIZE, SLOTS);
}

void *buf = mr_mempool_alloc(&pool, MR_WAIT_FOREVER);
/* fill, hand to another task */
mr_mempool_free(&pool, buf);   /* eventually */
```
