---
title: Memory pool
description: Fixed-block O(1) allocation, no fragmentation, no malloc.
---

A memory pool is a fixed array of fixed-size blocks with an internal
free list. Allocation pops the head of the free list; freeing pushes
back. Both are constant-time. No fragmentation because every block is
the same size.

Enabled by `MR_USE_MEMORY_POOLS=1` (default).

```c
#include "micrortos.h"
```

## Example

```c
#define SLOTS 8
#define SIZE  32

static uint8_t      pool_memory[SIZE * SLOTS];
static mr_mempool_t pool;

void init(void) {
    mr_mempool_init(&pool, pool_memory, SIZE, SLOTS);
}

void use_block(void) {
    void *buf = mr_mempool_alloc(&pool, MR_WAIT_FOREVER);
    if (!buf) return;
    /* fill, hand to a consumer, eventually free */
    mr_mempool_free(&pool, buf);
}
```

## Sizing

| Want | Set |
|---|---|
| Small messages, 4 in flight | `block_size = sizeof(msg)`, `count = 4` |
| Variable-size up to N bytes | Pick a bucket size = N (some waste) |
| Multiple in flight to DMA | `count = your DMA queue depth` |

A 16-block pool of 32-byte blocks uses:

- 512 B backing storage
- ~32 B for `mr_mempool_t`
- 0 B of free-list metadata (lives inside free blocks)
