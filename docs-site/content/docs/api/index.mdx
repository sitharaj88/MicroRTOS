The full public surface is exposed by a single header:

```c
#include "micrortos.h"
```

Internally that pulls in everything else. You don't need to include
sub-headers individually.

## Conventions

All public functions follow the same conventions:

- **Return type `mr_status_t`** — `MR_OK` (0) on success, one of the
  error constants otherwise.
- **Timeout argument** — milliseconds expressed as ticks via
  `MR_MS_TO_TICKS(ms)`. `MR_NO_WAIT` (0) for non-blocking,
  `MR_WAIT_FOREVER` (`UINT32_MAX`) for indefinite.
- **`_from_isr` variants** — call these from interrupt context. They
  never block and may set a `*yield_required` flag if a context switch
  should follow.

## Error codes

```c
typedef enum {
    MR_OK              = 0,
    MR_ERR_TIMEOUT     = 1,
    MR_ERR_FULL        = 2,
    MR_ERR_EMPTY       = 3,
    MR_ERR_PARAM       = 4,
    MR_ERR_STATE       = 5,
    MR_ERR_NOMEM       = 6,
    MR_ERR_DELETED     = 7,
    MR_ERR_ISR         = 8,
} mr_status_t;
```

Check the return value. The kernel never sets `errno`.

## Time

```c
#define MR_MS_TO_TICKS(ms)    (((uint32_t)(ms) * MR_TICK_RATE_HZ) / 1000U)
#define MR_TICKS_TO_MS(t)     ((uint32_t)(t) * 1000U / MR_TICK_RATE_HZ)

#define MR_WAIT_FOREVER       ((uint32_t)0xFFFFFFFF)
#define MR_NO_WAIT            ((uint32_t)0)

uint32_t mr_tick_get(void);   /* free-running 32-bit tick counter */
```
