---
title: Task notifications
description: The lightest-weight task signaling primitive — no separate object.
---

A notification is a 32-bit value attached to a task's TCB. No separate
allocation, no separate object — every task already has the slot. For
ISR-to-task or task-to-task signaling that doesn't need queuing, this
is the cheapest option.

Enabled by `MR_USE_TASK_NOTIFICATIONS=1` (default).

```c
#include "micrortos.h"
```

---

<Signature

Signals the task. If the task is waiting on a notification, it wakes.

## When to use

- **Single-event ISR → task** — lighter than a semaphore.
- **Counter** — ISR increments via `MR_NOTIFY_INCREMENT`; task processes
  batches.
- **Flag set** — multiple ISRs OR their flags into one notification.

```c
/* ISR */
mr_task_notify_from_isr(&worker_tcb, &yield);

/* Task */
while (1) {
    mr_task_wait_notification(MR_WAIT_FOREVER);
    drain_queue();
}
```

---

## Limits

- One pending notification per task. Subsequent signals before the task
  reads either coalesce (per `action`) or are lost (`SET_IF_NEW`).
- For queuing or multiple distinct events, use a real queue or event
  group.
