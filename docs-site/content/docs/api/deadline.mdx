---
title: Deadline (EDF)
description: Earliest Deadline First scheduling for hard real-time tasks.
---

Enabled by `MR_USE_EDF_SCHEDULER=1`. EDF tasks coexist with
fixed-priority tasks.

## `mr_deadline_init`

```c
void mr_deadline_init(void);
```

Initializes the EDF scheduler state. Call once after `mr_kernel_init`.

## `mr_deadline_task_create`

```c
mr_status_t mr_deadline_task_create(mr_tcb_t *tcb,
                                         uint32_t    period_ms,
                                         uint32_t    deadline_ms,
                                         uint32_t    wcet_ms);
```

Registers an existing task with EDF parameters. Call after
`mr_task_create`.

| Argument | Meaning |
|---|---|
| `period_ms` | Time between job releases |
| `deadline_ms` | Relative deadline from job release (typically ≤ period) |
| `wcet_ms` | Worst-case execution time per job |

The kernel performs an admission test using the Liu-Layland bound; the
call returns `MR_ERR_STATE` if adding the task would exceed
schedulable utilization.

## `mr_deadline_job_complete`

```c
void mr_deadline_job_complete(void);
```

Call at the end of each periodic iteration. Marks the current job done
and schedules the next release.

```c
void edf_task(void *arg) {
    while (1) {
        do_work();
        mr_deadline_job_complete();
    }
}
```

## `mr_deadline_set_miss_callback`

```c
typedef void (*mr_deadline_miss_cb)(mr_deadline_task_t *task);

void mr_deadline_set_miss_callback(mr_tcb_t           *tcb,
                                      mr_deadline_miss_cb cb);
```

Sets a callback that fires when the task misses a deadline. Useful for
logging and recovery.

## `mr_deadline_admission_test`

```c
bool mr_deadline_admission_test(uint32_t period_ticks, uint32_t wcet_ticks);
```

Check if a new task would fit the schedule before calling
`mr_deadline_task_create`.

## `mr_deadline_exact_test`

```c
bool mr_deadline_exact_test(uint32_t period_ticks,
                               uint32_t deadline_ticks,
                               uint32_t wcet_ticks);
```

More precise than the Liu-Layland bound, using processor demand
analysis.

## Statistics

```c
uint16_t mr_deadline_get_miss_count(mr_tcb_t *tcb);
uint16_t mr_deadline_get_job_count(mr_tcb_t *tcb);
int32_t  mr_deadline_get_slack(mr_tcb_t *tcb);
uint8_t  mr_deadline_get_utilization(void);     /* percent */
```

## Example

```c
static mr_tcb_t  fast_tcb, slow_tcb;
static uint8_t     fast_stack[160], slow_stack[160];

void init(void) {
    mr_kernel_init();
    mr_deadline_init();

    mr_task_create(&fast_tcb, "fast", fast_task, NULL, 2,
                     fast_stack, sizeof(fast_stack));
    mr_task_create(&slow_tcb, "slow", slow_task, NULL, 2,
                     slow_stack, sizeof(slow_stack));

    mr_deadline_task_create(&fast_tcb,
                              /* period   */ 50,
                              /* deadline */ 40,
                              /* wcet     */ 5);
    mr_deadline_task_create(&slow_tcb, 200, 200, 20);

    mr_kernel_start();
}
```
