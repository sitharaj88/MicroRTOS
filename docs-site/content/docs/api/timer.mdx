---
title: Timer
description: Software timers — one-shot and periodic.
---

Enabled by `RTOS_USE_TIMERS=1` (default). The kernel creates a dedicated
"timer task" that runs all callbacks; the tick ISR just maintains a
sorted timer list.

## `rtos_timer_init`

```c
void rtos_timer_init(rtos_timer_t       *timer,
                     const char         *name,
                     rtos_timer_callback callback,
                     uint32_t            period_ticks,
                     bool                auto_reload);
```

`auto_reload = true` makes it periodic; `false` makes it one-shot.

The callback signature is:

```c
void my_callback(rtos_timer_t *timer);
```

It runs in the timer task context — you can call any kernel API.

## `rtos_timer_start` / `rtos_timer_stop`

```c
rtos_status_t rtos_timer_start(rtos_timer_t *timer);
rtos_status_t rtos_timer_stop(rtos_timer_t *timer);
```

`start` arms the timer; `stop` cancels a pending expiration. Calling
`start` on an already-running timer resets the countdown.

## `rtos_timer_change_period`

```c
rtos_status_t rtos_timer_change_period(rtos_timer_t *timer,
                                        uint32_t      new_period_ticks);
```

Adjusts the period. If running, the new period applies to the next
expiration cycle.

## `rtos_timer_reset`

```c
rtos_status_t rtos_timer_reset(rtos_timer_t *timer);
```

Restart the countdown from now, keeping the existing period.

## `rtos_timer_is_active`

```c
bool rtos_timer_is_active(rtos_timer_t *timer);
```

## Tunables

```c
/* In rtos_config.h */
#define RTOS_TIMER_TASK_PRIORITY    1
#define RTOS_TIMER_TASK_STACK_SIZE  96
#define RTOS_TIMER_QUEUE_LENGTH     8
```

## Example: periodic blink

```c
static rtos_timer_t blink;

static void on_tick(rtos_timer_t *t) {
    (void)t;
    PORTB ^= (1 << PB5);
}

void init(void) {
    rtos_timer_init(&blink, "blink", on_tick,
                    RTOS_MS_TO_TICKS(500), /* periodic */ true);
    rtos_timer_start(&blink);
}
```

## Example: one-shot debounce

```c
static rtos_timer_t debounce;

static void check_button(rtos_timer_t *t) {
    (void)t;
    if (PINB & (1 << PB0)) {
        button_pressed();
    }
}

void on_button_edge(void) {
    rtos_timer_init(&debounce, "deb", check_button,
                    RTOS_MS_TO_TICKS(20), /* one-shot */ false);
    rtos_timer_start(&debounce);
}
```
