---
title: Software timer
description: One-shot and periodic timers without burning a TCB per timer.
---

A software timer runs your callback after a delay, optionally repeating.
All timers share one **timer task** that the kernel creates on
`mr_kernel_init` — your callbacks run in normal task context, not in
the tick ISR, so they can call any kernel API.

Enabled by `MR_USE_TIMERS=1` (default).

```c
#include "micrortos.h"
```

## `mr_timer_start` / `mr_timer_stop`

<Signature
  name="mr_timer_start / mr_timer_stop"

mr_status_t mr_timer_stop(mr_timer_t *timer);`}
  badges={[{ label: 'Non-blocking', variant: 'success' }]}

`start` arms the timer (or rearms it, restarting the countdown).
`stop` cancels a pending expiration.

## Pattern: periodic heartbeat

```c
static mr_timer_t heartbeat;

static void on_tick(mr_timer_t *t) {
    (void)t;
    PORTB ^= (1 << PB5);
}

void init(void) {
    mr_timer_init(&heartbeat, "hb", on_tick,
                  MR_MS_TO_TICKS(500), /* periodic */ true);
    mr_timer_start(&heartbeat);
}
```

---

## Pattern: one-shot debounce

```c
static mr_timer_t debounce;

static void check_button(mr_timer_t *t) {
    (void)t;
    if (PINB & (1 << PB0)) button_pressed();
}

void on_button_edge(void) {
    mr_timer_init(&debounce, "deb", check_button,
                  MR_MS_TO_TICKS(20), /* one-shot */ false);
    mr_timer_start(&debounce);
}
```

## Cost

| Per timer | ~16 B state + a 12 B list node |
| Timer task | One TCB + its stack (96 B default) |
