---
title: Timer
description: Software timers — one-shot and periodic.
---

Enabled by `MR_USE_TIMERS=1` (default). The kernel creates a dedicated
"timer task" that runs all callbacks; the tick ISR just maintains a
sorted timer list.

## `mr_timer_init`

```c
void mr_timer_init(mr_timer_t       *timer,
                     const char         *name,
                     mr_timer_callback callback,
                     uint32_t            period_ticks,
                     bool                auto_reload);
```

`auto_reload = true` makes it periodic; `false` makes it one-shot.

The callback signature is:

```c
void my_callback(mr_timer_t *timer);
```

It runs in the timer task context — you can call any kernel API.

## `mr_timer_start` / `mr_timer_stop`

```c
mr_status_t mr_timer_start(mr_timer_t *timer);
mr_status_t mr_timer_stop(mr_timer_t *timer);
```

`start` arms the timer; `stop` cancels a pending expiration. Calling
`start` on an already-running timer resets the countdown.

## `mr_timer_change_period`

```c
mr_status_t mr_timer_change_period(mr_timer_t *timer,
                                        uint32_t      new_period_ticks);
```

Adjusts the period. If running, the new period applies to the next
expiration cycle.

## `mr_timer_reset`

```c
mr_status_t mr_timer_reset(mr_timer_t *timer);
```

Restart the countdown from now, keeping the existing period.

## `mr_timer_is_active`

```c
bool mr_timer_is_active(mr_timer_t *timer);
```

## Tunables

```c
/* In mr_config.h */
#define MR_TIMER_TASK_PRIORITY    1
#define MR_TIMER_TASK_STACK_SIZE  96
#define MR_TIMER_QUEUE_LENGTH     8
```

## Example: periodic blink

```c
static mr_timer_t blink;

static void on_tick(mr_timer_t *t) {
    (void)t;
    PORTB ^= (1 << PB5);
}

void init(void) {
    mr_timer_init(&blink, "blink", on_tick,
                    MR_MS_TO_TICKS(500), /* periodic */ true);
    mr_timer_start(&blink);
}
```

## Example: one-shot debounce

```c
static mr_timer_t debounce;

static void check_button(mr_timer_t *t) {
    (void)t;
    if (PINB & (1 << PB0)) {
        button_pressed();
    }
}

void on_button_edge(void) {
    mr_timer_init(&debounce, "deb", check_button,
                    MR_MS_TO_TICKS(20), /* one-shot */ false);
    mr_timer_start(&debounce);
}
```
